Regulation 3

3. In these Regulations—

" the Board " means Bord na gCon;

" double event " means an event in which two greyhound races taking place on the same race track are involved;

" multiple event " means an event in which more than two greyhound races taking place on the same race track are involved;

" totalisator to which these Regulations relate " means a totalisator set up on a greyhound race track.
