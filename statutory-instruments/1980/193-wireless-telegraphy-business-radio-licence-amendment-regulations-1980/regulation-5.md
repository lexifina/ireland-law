Regulation 5

5. Regulation 7 of the Regulations of 1957 is hereby amended by—

( a ) the substitution of "four pounds" for "three pounds" in both places where it occurs in paragraph (a);

( b ) the substitution of "four pounds" for "three pounds" in both places where it occurs and of "fifteen pounds" for "twelve pounds" in paragraph (b);

( c ) the substitution of "nineteen pounds" and "four pounds" for "fifteen pounds" and "three pounds", respectively, in paragraph (c); and

( d ) the substitution of "nineteen pounds", "four pounds" and "fifteen pounds" for "fifteen pounds", "three pounds" and "twelve pounds", respectively, in paragraph (d);

and the said Regulation 7, and so amended, is set out in the Table to this Regulation.

TABLE.

7. A fee shall be payable on the issue and renewal of a licence and such fee shall be calculated on the following basis:

( a ) system comprising base and mobile stations only or system comprising mobile stations only: a fixed sum of four pounds plus four pounds for each station,

( b ) system comprising base, repeater and mobile stations or mobile and repeater stations: a fixed sum of four pounds plus four pounds for each base station and each mobile station plus fifteen pounds in respect of each repeater station,

( c ) system comprising two fixed stations only, that is to say, a fixed point-to-point system: a fixed sum of nineteen pounds plus four pounds for each station,

( d ) system comprising two fixed stations with repeater stations, that is to say, a fixed point-to-point system with repeater stations: a fixed sum of nineteen pounds plus four pounds for each fixed station plus fifteen pounds in respect of each repeater station.

EXPLANATORY NOTE.

The purpose of these Regulations is to provide for an increase in the fees payable under the Wireless Telegraphy (Business Radio Licence) Regulations, 1949 to 1957 as follows:

"Annual" Business Radio Licences

( a ) System comprising base and mobile stations only;

(i) Fixed Sum

from £5 to £7

(ii) For each Station

from £5 to £7

( b ) System comprising base, repeater and mobile stations or mobiles and repeater stations;

(i) Fixed Sum

from £5 to £7

(ii) For each base and mobile station

from £5 to £7

(iii) For each repeater station

from £20 to £25

( c ) System comprising two fixed stations only;

(i) Fixed Sum

from £25 to £32

(ii) For each station

from £5 to £7

( d ) System comprising two fixed stations with repeater stations;

(i) Fixed Sum

from £25 to £32

(ii) For each fixed station

from £5 to £7

(iii) For each repeater station

from £20 to £25
