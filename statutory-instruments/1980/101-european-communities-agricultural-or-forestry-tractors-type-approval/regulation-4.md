Regulation 4

4. The following Regulation is hereby substituted for Regulation 8 of the Regulations of 1979:

" 8. (1) The manufacturer (or his authorised representative) of a type tractor in respect of which a type approval certificate has been issued and is in force shall, in respect of each tractor manufactured in conformity with the type tractor, complete a certificate of conformity.

(2) The manufacturer (or his authorised representative) of a separate technical unit of a type which has been granted type approval shall affix to each unit manufactured in conformity with the approved type the trade name or mark, the type and (if the appropriate scheduled directive so requires) the type approval number.".
