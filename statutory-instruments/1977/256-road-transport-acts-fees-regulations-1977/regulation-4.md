Regulation 4

4. The following is hereby substituted for the First Schedule to the Road Transport Act, 1933 , Regulations, 1955 ( S.I. No. 69 of 1955 ):—

"FIRST SCHEDULE.

FEES

(1) Merchandise Licences:

( a ) On application for a merchandise licence

Ten pounds

( b ) On application for the renewal of a merchandise licence

Five pounds

( c ) On application for the transfer of a merchandise licence

Ten pounds

(2) Vehicle Plates:

( a ) On application for a vehicle plate

Ten pounds

( b ) On application for the issue of a vehicle plate by way of replacement

Ten pounds

( c ) On application for a vehicle plate if the conditions set out in Article 4 (2) are complied with

One pound

(3) On application for an order under Part V of the Act

Four pounds"
