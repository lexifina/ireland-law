FIFTH SCHEDULE

Rates of Firearm Certificate Duty

Section 16. £ s. d. 1. For a firearm certificate for a pistol, including an air pistol, or revolver 0 10 0 2. For a firearm certificate for a rifle, including a miniature rifle 1 10 0 3. For a firearm certificate for an airgun, including an air rifle 1 0 0 4. For a firearm certificate for a prohibited weapon 0 10 0 5. For a firearm certificate for a shot-gun to which the provisions of section 12 of the Firearms Act, 1964, apply 0 15 0 6. For any other firearm certificate— For one such certificate 3 5 0 Where two or more such certificates are granted to the same person (not necessarily at the same time) and expire on the same date— For the first such certificate 3 5 0 For the second and every subsequent such certificate 0 15 0
