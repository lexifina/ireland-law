Admissibility of codes of practice

215. A document bearing the seal of the Minister and purporting to be a code of practice or, where such a code has been amended under section 214, the code as so amended shall be admissible in evidence—

(a) in any proceedings before a court or tribunal, or

(b) in any other proceedings concerning the provision of this Act to which the code relates.
